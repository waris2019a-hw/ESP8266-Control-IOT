Code Arduino บนบอร์ด ESP8266
1.เชื่อมต่อ Wi-Fi จากโทรศัพท์หรือคอมพิวเตอร์:
เชื่อมต่อตรงเข้าหา ESP8266เปิดการค้นหา Wi-Fi บนมือถือหรือคอมพิวเตอร์ของคุณ
เลือกเชื่อมต่อกับ Wi-Fi ชื่อ ESP8266-Control-IOT
ป้อนรหัสผ่าน 12345678

วิธีตรวจสอบความถูกต้อง: 

อุปกรณ์ของคุณจะแสดงสถานะว่า "Connected" 
(หากแสดงว่า No Internet Connection ถือเป็นเรื่องปกติเพราะไม่มีอินเทอร์เน็ตจริง)

2.เปิด Web Browser เพื่อสั่งงาน IO:ผ่าน IP 192.168.4.1
เปิดเว็บเบราว์เซอร์ (เช่น Google Chrome หรือ Safari)
พิมพ์ Address: 192.168.4.1 แล้วกด Enter
หน้าควบคุมจะแสดงปุ่ม ON และ OFF
3.เมื่อกดปุ่ม ON ไฟ LED บนบอร์ด (GPIO2) จะติด 
และเมื่อกดปุ่ม OFF ไฟ LED จะดับลงทันที


version2 ชื่อไฟล์ว่า esp_app_iot.ino
IP Address สำหรับเข้าหน้าเว็บคือ 192.168.4.1

นี่คือขั้นตอนการเข้าใช้งาน:

ใช้มือถือหรือคอมพิวเตอร์เชื่อมต่อ Wi-Fi ชื่อ: ESP8266-Control-IoT

ใส่รหัสผ่าน: 12345678

หน้าตาเว็บใหม่: เพิ่มกล่องควบคุม "AUTOMATION (A0 TRIGGER)" สามารถเลือก Manual หรือ Auto ระบุเครื่องหมาย > (มากกว่า) หรือ < (น้อยกว่า) และใส่ตัวเลข 0-1023 ได้อย่างอิสระ لكلขา

ป้ายกำกับ UI: หากตั้งค่าโหมดเป็น Auto ไว้ จะมีแถบข้อความ "AUTO" สีม่วงโผล่ขึ้นมาเหนือปุ่ม หากผู้ใช้งานคลิกปุ่มสลับการทำงานเองด้วยมือ ระบบจะตัดกลับมาเป็นโหมด Manual ให้ทันทีโดยอัตโนมัติ

การทำงานเบื้องหลัง: ฟังก์ชัน checkAutoRules() จะดึงค่า A0 มาตรวจสอบทุกๆ 100 มิลลิวินาที (โดยไม่ใช้ delay เพื่อไม่ให้ Web Server ค้าง) ถ้าตรงเงื่อนไขไฟก็จะติด ถ้านอกเหนือเงื่อนไขไฟจะดับลง

กดเปิด-ปิดเองได้ตามปกติ: ปุ่ม (D5, D6, D7) ในหมวด BUTTONS CONTROL ยังสามารถใช้คลิกเพื่อสั่งเปิดและปิดไฟได้ทันทีเหมือนโค้ดเวอร์ชันแรก

สลับโหมดให้อัตโนมัติ: หากขานั้นกำลังทำงานอยู่ในโหมด Auto แล้วคุณไป กดปุ่มเปิด/ปิดด้วยตัวเอง ระบบจะรับรู้ว่าคุณต้องการเข้ามาแทรกแซง และจะเปลี่ยนสถานะขานั้นกลับเป็นโหมด Manual ให้อัตโนมัติ (ป้ายคำว่า "AUTO" สีม่วงด้านบนปุ่มจะหายไป)
