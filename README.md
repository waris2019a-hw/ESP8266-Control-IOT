1.เชื่อมต่อ Wi-Fi จากโทรศัพท์หรือคอมพิวเตอร์:
เชื่อมต่อตรงเข้าหา ESP8266เปิดการค้นหา Wi-Fi บนมือถือหรือคอมพิวเตอร์ของคุณ
เลือกเชื่อมต่อกับ Wi-Fi ชื่อ ESP8266-Control-IOT
ป้อนรหัสผ่าน 12345678

วิธีตรวจสอบความถูกต้อง: 

อุปกรณ์ของคุณจะแสดงสถานะว่า "Connected" 
(หากแสดงว่า No Internet Connection ถือเป็นเรื่องปกติเพราะไม่มีอินเทอร์เน็ตจริง)

2.เปิด Web Browser เพื่อสั่งงาน IO:ผ่าน IP 192.168.4.1
เปิดเว็บเบราว์เซอร์ (เช่น Google Chrome หรือ Safari)
พิมพ์ Address: 192.168.4.1 แล้วกด Enter
หน้าควบคุมจะแสดงปุ่ม ON และ OFF
3.เมื่อกดปุ่ม ON ไฟ LED บนบอร์ด (GPIO2) จะติด 
และเมื่อกดปุ่ม OFF ไฟ LED จะดับลงทันที
